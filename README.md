## ♿ Accesibilidad (WCAG 2.2 AA) y Performance
- Contraste de colores verificado (≥ 4.5:1).
- Navegación 100% operable por teclado (con enlace "Saltar al contenido" oculto).
- Soporte para preferencias del sistema (`prefers-reduced-motion`).
- Gestión de foco (focus trap) y atributos ARIA en menú y modal (`<dialog>`).
- Optimizado para obtener +90 en Lighthouse (Performance, Accesibilidad, Mejores Prácticas, SEO).
